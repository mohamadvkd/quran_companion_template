# رفيق القرآن — Quran Companion

قالب Flutter عربي حديث وقابل للتوسعة لبناء تطبيق قرآن كريم بجودة إنتاجية. القالب يعتمد على Flutter Material 3، يدعم RTL من البداية، ويضع طبقة واجهة نظيفة يمكن ربطها لاحقًا بمصدر بيانات محلي أو API.

## المزايا الحالية

- تجربة عربية RTL كاملة.
- تصميم هادئ مناسب لتطبيقات القرآن: أخضر زمردي، رملي، وبطاقات ناعمة.
- دعم الوضع الفاتح والداكن من داخل الإعدادات.
- شريط تنقل سفلي: الرئيسية، المصحف، المحفوظات، الإعدادات.
- بطاقة متابعة القراءة مع آخر موضع قراءة.
- قائمة سور قابلة للتوسع لاحقًا بالبحث والتصنيفات.
- شاشة قراءة أولية تحافظ على قابلية إضافة النص القرآني والتفسير والترجمة.
- مكونات UI معاد استخدامها داخل `lib/core/widgets`.
- فصل مبدئي بين الثيم والبيانات والشاشات.

## التشغيل

1. ثبّت Flutter 3.22 أو أحدث.
2. من داخل مجلد المشروع شغّل:

```bash
flutter pub get
flutter run
```

إن أنشأت مشروعًا جديدًا عبر `flutter create`، انسخ مجلد `lib` وملف `pubspec.yaml` ومجلد `assets` إلى المشروع الجديد، أو استخدم هذا المجلد مباشرة بعد تثبيت Flutter.

## التوصيات للمرحلة التالية

- استبدال `DemoData` بمستودع بيانات `QuranRepository`.
- إضافة قاعدة بيانات محلية للتنزيل دون اتصال.
- إضافة محرك بحث وفهرسة للسور والآيات.
- إضافة مشغل تلاوة مع حفظ موضع التشغيل.
- إضافة اختبارات golden واختبارات وصولية للنصوص وأحجام الخط.
- استخدام خط عربي قرآني مرخص داخل `assets/fonts` عند اختيار مصدر النص.

## ملاحظة حقوقية

القالب لا يضم نصًا قرآنيًا كاملًا أو ملفات صوتية. عند إضافة المحتوى، استخدم مصدرًا موثقًا وتحقق من الترخيص ودقة النص قبل النشر.
